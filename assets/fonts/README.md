# Menu typefaces

All three typefaces are under the SIL Open Font License 1.1 (the licence texts are alongside). They were downloaded on 2026-10-25 from the official Google Fonts repository (`github.com/google/fonts`, `ofl/`).

| File | Typeface | Use | Licence |
|---|---|---|---|
| `PoiretOne-Regular.ttf` | Poiret One, © 2011 The Poiret One Project Authors | the title's deco capitals | `OFL-PoiretOne.txt` |
| `CormorantSC-Medium.ttf` | Cormorant SC, © 2015 The Cormorant Project Authors | the choices and headings in small capitals | `OFL-CormorantSC.txt` |
| `CormorantGaramond-Variable.ttf`, `CormorantGaramond-Italic-Variable.ttf` | Cormorant Garamond (variable weight), © 2015 The Cormorant Project Authors | page text | `OFL-CormorantGaramond.txt` |

The Cormorant Garamond files were renamed from `CormorantGaramond[wght].ttf` and `CormorantGaramond-Italic[wght].ttf`. Loaded by `scripts/UI/MenuType.gd`.
